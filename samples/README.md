# Drum machine samples

All four kits are published as **Public Domain** in the [oramics/sampled](https://github.com/oramics/sampled) collection (folder `DM/`), from which they were copied unchanged (the `tr505-` file prefix was dropped).

| Kit | Machine | Original source |
| --- | --- | --- |
| `CR-78` | Roland CompuRhythm CR-78 | <http://www.boxedear.com/free.html> |
| `LM-2` | LinnDrum LM-2 | <http://machines.hyperreal.org/manufacturers/Linn/LinnDrum/> |
| `MRK-2` | Maestro Rhythm King MRK-2 | <http://www.submodern.com/slowburn/?p=736> |
| `TR-505` | Roland TR-505 | <http://www.progsounds.com/downloads/progsounds-roland-tr-505-samples-pack> |

`manifest.json` lists the files the app loads.
